Challenge Categories

Engineered exclusively by the EST Guelmim Red Team. Each problem set models practical security vectors across enterprise and low-level environments.

CAT-01 // WEB 100 — 500 PTS

Web Exploitation

SSRF vectors, GraphQL schema leaks, JWT token bypasses, DOM clobbering, and modern server-side template execution.

Dynamic Decay Active Live Instance
CAT-02 // PWN 200 — 500 PTS

Binary Exploitation

Glibc heap exploitation (tcache poisoning, fastbins), ret2dlresolve, return-oriented programming (ROP), and shellcrafting.

Dynamic Decay Active x86_64 / ARM
CAT-03 // REV 150 — 500 PTS

Reverse Engineering

Stripped compiled binaries, anti-debugging routines, custom VM bytecodes, unpackers, and obfuscated logic validation.

Dynamic Decay Active Static & Dynamic
CAT-04 // CRYPTO 150 — 500 PTS

Cryptography

Elliptic curve discrete logarithms, lattice reduction (LLL), faulty RSA key generation, and custom PRNG state recovery.

Dynamic Decay Active Pure Mathematics

Digital Forensics

Volatile memory reconstruction via Volatility 3, raw network pcap stream reassembly, and disk artifact recovery.

Dynamic Decay Active Memory / PCAP / Disk

OSINT & Reconnaissance

Rules of Engagement

OFFICIAL POLICY
01. Scope Strictness

Designated challenge targets are strictly in scope. Scoring infrastructure, platform host servers, judging nodes, and other participants are entirely off-limits.

02. Infrastructure Protection

Denial of Service (DoS/DDoS) and destructive actions targeting competition infrastructure or instances will result in immediate disqualification.

03. Flag Sharing Policy

Sharing flags, keys, solve payloads, or collaborative writeups before the round conclusion is prohibited. Flag sharing triggers disqualification of all parties involved.
