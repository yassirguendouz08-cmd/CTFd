CHALLENGE CATEGORIES

Engineered exclusively by the EST Guelmim Red Team. Each problem set models practical security vectors encountered across modern enterprise and critical systems.

CAT-01 // WEB 10 Challenges

Web Exploitation

SSRF vectors, GraphQL schema leaks, modern JWT desynchronization, DOM clobbering, and prototype pollution primitives in hardened stacks.

Points: 100 — 500 Dynamic Decay
CAT-02 // CRYPTO 8 Challenges

Cryptography

Elliptic curve discrete logs, lattice reduction (LLL), non-standard RSA parameter leakage, fault injections, and zero-knowledge proofs.

Points: 150 — 500 Dynamic Decay
CAT-03 // FORENSICS 8 Challenges

Digital Forensics

Volatile memory triage via Volatility 3, raw pcap telemetry reconstruction, encrypted LUKS partitions, and embedded IoT firmware extractions.

Points: 100 — 450 Dynamic Decay
CAT-04 // REV 8 Challenges

Reverse Engineering

Stripped x86_64/ARM64 binaries, anti-debugging routines, custom virtual machine bytecode dispatchers, and obfuscated Android DEX structures.

Points: 150 — 500 Dynamic Decay
CAT-05 // PWN 8 Challenges

Binary Exploitation (Pwn)

Glibc heap exploitation (tcache poisoning, fastbins), ret2dlresolve, return-oriented programming (ROP), and simplified Linux kernel module escapes.

Points: 200 — 500 Dynamic Decay
CAT-06 // OSINT 6 Challenges

OSINT & Reconnaissance

Geolocation validation through topography, corporate graph mapping, certificate transparency logs, and satellite imagery triangulation.

Points: 100 — 350 Dynamic Decay

ETHICAL BOUNDARIES & CODE OF CONDUCT

Rules of Engagement

ENFORCED BY CTF MARSHALS
01. Scope Strictness

Designated challenge targets strictly in scope. Scoring infrastructure, judging systems, hosting clusters, and fellow participants are strictly off-limits.

02. No Denial of Service

Denial of service (DoS/DDoS) attacks against competition infra or challenge instances result in immediate, non-negotiable squad disqualification.

03. No Flag Sharing

Sharing flags, hints, solve scripts, or writeups prior to competition conclusion is prohibited. Plagiarized submissions will trigger zero-point penalties.
