# Locally served typography

Inter, Space Grotesk and JetBrains Mono came from the official Google Fonts
stylesheet and fonts.gstatic.com on 11 October 2026. ../css/fonts.css maps the
original family/weight definitions to local TTF files. The platform does not need
Google Fonts network access at runtime.

OFL licenses from Google's google/fonts repository are included per family.
Arabic falls back to the device's Arabic-capable system font.
